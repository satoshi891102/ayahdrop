# AyahDrop — Summary

**What:** A beautiful Quran verse card generator for social media. Pick any ayah from all 114 surahs, choose from 8 premium card styles, and download as a 1080x1080 PNG ready for Instagram, WhatsApp, or Twitter.

**Why:** Islamic content creators (#QuranQuotes has 15M+ posts on Instagram) need tools to create beautiful verse cards. Existing tools are ugly, complicated, or don't handle Arabic text properly. AyahDrop does Arabic calligraphy right with the Amiri font, proper RTL, and Bismillah ornaments.

**How:** Next.js 16 static export on Vercel. AlQuran.cloud API for Quranic text (Arabic + Sahih International translation). html-to-image for high-res PNG export. Self-hosted fonts for reliable export quality.

**Status:** LIVE at https://ayahdrop.vercel.app — BQS quality gate passed 10/10.

**Features:**
- All 114 surahs, any ayah
- 8 card styles (4 free, 4 PRO)
- 6 themed collections (Patience, Trust, Gratitude, Mercy, Guidance, Prophet ﷺ)
- URL-based sharing (?s=2&a=255)
- Share to WhatsApp, X, Copy text
- OG image for social previews
- Mobile responsive
- Self-hosted fonts for reliable PNG export

**What's next:** User acquisition via Islamic content community, SEO for "Quran quote generator", potential freemium with premium styles.
